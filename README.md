# 智能文件搜索与复制工具

## 功能概述

本工具是一个通用性文件搜索工具，支持从TXT文件读取项目名称列表，在源目录中模糊匹配相关文件，并将匹配到的文件复制到目标文件夹。

**通用性设计**：不限于特定领域，可用于任何需要按名称列表搜索文件的场景。

## 快速开始

```bash
# 第1步：搜索（仅用项目名称）
python main.py

# 或带关键词增加权重
python main.py 关键词1 关键词2

# 第2步：打开Excel查看评分结果，选择要复制的文件

# 第3步：执行复制
python main.py run
```

## 安装要求

- Python 3.6 或更高版本
- openpyxl 库

```bash
pip install -r requirements.txt
```

## 配置文件

编辑 `config.json`：

```json
{
  "items_file": "name.txt",
  "source_dir": "E:\\源文件目录",
  "target_dir": "H:\\输出目录",
  "threshold": 0.8
}
```

| 参数 | 说明 |
|------|------|
| `items_file` | 项目名称列表TXT文件路径 |
| `source_dir` | 源文件目录路径 |
| `target_dir` | 复制目标目录路径 |
| `threshold` | 模糊匹配阈值（0-1），默认0.8 |

## 评分规则

| 评分项 | 说明 | 分值 |
|--------|------|------|
| 项目名称匹配度 | 文件名与项目名称的相似度 | 0-100分 |
| 关键词加分（仅文件名） | 文件名含关键词 | 每个+10分 |
| 关键词加分（仅路径） | 路径含关键词 | 每个+10分 |
| 关键词加分（两者都有） | 文件名和路径都含关键词 | 每个+15分（额外奖励） |
| **总分** | 名称分 + 关键词分 | **0-145分** |

**颜色标识：**
- 🟢 绿色（≥90分）：最佳匹配
- 🟡 黄色（70-89分）：较好匹配

## 使用方法

### 命令行版本

```bash
# 基础搜索（仅用项目名称匹配）
python main.py

# 带关键词搜索（关键词增加匹配权重，可多关键词）
python main.py 关键词1
python main.py 关键词1 关键词2
python main.py 关键词1 关键词2 关键词3

# 执行复制（按Excel中的选择）
python main.py run
```

### GUI版本

直接运行 `FileSearchTool.exe` 或：

```bash
python gui_main.py
```

GUI版本功能：
- 可视化配置界面
- 实时显示搜索进度
- 表格展示搜索结果
- 双击切换是否复制
- 一键导出Excel
- 一键执行复制

### Excel 报表说明

生成的Excel文件保存在 `target_dir` 目录，文件名格式：`搜索结果_YYYYMMDD_HHMMSS.xlsx`

**报表特点：**
- **按项目分组**：同一项目的匹配项放在一起
- **组内按评分排序**：评分最高的排在前面
- **颜色区分**：多匹配的项目使用不同背景色
- **高亮重复项**：有多个匹配的项目名称显示红色背景
- **显示未匹配**：未找到匹配的项目也显示在表格中（灰色背景）
- **智能默认选择**：每组默认只选中评分最高的文件

**Excel 列说明：**

| 列名 | 说明 |
|------|------|
| 序号 | 行号 |
| 项目名称 | 匹配的项目（多匹配时红色高亮） |
| 匹配数 | 该项目有多少个匹配文件 |
| 源文件路径 | 文件完整路径 |
| 源文件名 | 原始文件名 |
| 目标文件名 | 复制后的文件名（可修改） |
| 名称匹配度 | 0-100分 |
| 关键词加分 | 0-45分 |
| 总分 | 名称分+关键词分 |
| 是否复制 | 是/否（默认每组只选第一个） |
| 备注 | 匹配的关键词详情 |

## 输入文件格式

### 项目名称列表（name.txt）

```
# 这是注释行

1→项目A-001
2→项目B-002
3→项目C-003

4. 项目D-004
5) 项目E-005

项目F-006
```

支持自动移除行号前缀、跳过空行和 `#` 开头的注释行。

## 使用示例

**场景1：基础搜索**
```bash
python main.py
```
仅用项目名称匹配，找到所有相关文件。

**场景2：带关键词搜索**
```bash
python main.py 竣工 2024
```
文件名或路径含"竣工"或"2024"的文件会获得额外加分，排在前面。

**场景3：多关键词组合**
```bash
python main.py 关键词1 关键词2 关键词3
```
同时匹配多个关键词，加分叠加。如果关键词同时匹配文件名和路径，可获得额外奖励分。

## 文件复制规则

- 保留原始文件属性
- 自动处理重名（添加编号后缀，如 `filename_001.ext`）
- 只复制Excel中标记为"是"/TRUE的文件

## 目录结构

```

├── README.md             # 使用说明
└── output/               # 打包输出目录

```

使用 cx_Freeze 打包为可执行文件：

```bash
python setup.py build
```

打包后的文件位于 `output/` 目录。
